收入表和支出表欄位都沒和網頁顯示一致，請依照附件欄位
收入表欄位：收據編號 開立時間 姓名 地址 辦理項目 科目 規格 金額(元) 選項人數 系統備註 經手人備註 PDF連結 收入日期 經手人
支出表欄位：收據編號 開立時間 姓名 辦理項目 科目 規格 金額(元) 詳細內容 系統備註 經手人備註 PDF連結 支出日期 經手人
除了收入日期 經手人和支出日期 經手人不冋在收執聯和存根聯，其他項目都要
辦理項目： 收入表直接帶收入，支出表直接帶支出
系統備註：
1.收入表為科目&規格&人數，例如：科目選光明燈，帶出規格選項，選擇300元，最後人數用輸入或＋-, 人數選2， 最後算出金額為600元, 系統備註為光明燈300元人數2人金額為600元
2.支出表為科目&規格&詳細內容，例如：科目選法會支出，帶出規格選項，選擇三月聖誕，詳細內容：買花， 金額填入800元, 系統備註為法會支出三月聖誕買花金額為800元
收執聯和存根聯：收入和支出格式要統一，都用A5， 同時印在一張上面，顯示不要被切掉，如附件
PDF連結網路和google表單都要有
